Petits Pas

Six petits jeux pour les enfants de 4 à 7 ans avec un syndrome 22q11 : syllabes, sons, voix, journée en images, émotions et coin calme.

💻 Sur PC (Windows) : installe XDK Hub, va dans « Jeux pour enfants » et tape le même code.

Le code est retenu sur cet appareil : il suffit de le taper une fois. C'est le même code que pour Tchac !
