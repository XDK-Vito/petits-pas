# Petits Pas

Six petits jeux pour les enfants de 4 à 7 ans avec un syndrome 22q11 : syllabes, loto des sons, fusée à la voix, journée en images, émotions et coin calme.

Site : https://xdteamdev.github.io/petits-pas/

L'accès se fait avec un code donné aux familles. Sans code, les jeux restent chiffrés.
