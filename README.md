# Petits Pas

Six petits jeux pour les enfants de 4 à 7 ans avec un syndrome 22q11 : syllabes, loto des sons, fusée à la voix, journée en images, émotions et coin calme.

Site : https://xdk-vito.github.io/petits-pas/ (jouer dans le navigateur ou télécharger l'appli Android). Sur PC : XDK Hub, catégorie « Jeux pour enfants ».

L'accès se fait avec le code donné aux familles (le même que pour Tchac !). Sans code, les jeux et l'appli restent chiffrés.
